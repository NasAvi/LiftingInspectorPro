מנהל תסקירי מכונות הרמה

לטבלת תסקירים (ללא צפייה בתסקיר):
1. בנייד → הגדרות → "ייצוא מטא-דאטה תסקירים למחשב"
2. חבר USB → העתק machine_reports_export_...json מ-Download למחשב
3. לחץ "טען קובץ ייצוא מנייד" למעלה

לצפייה בתסקירים (HTML):
4. בנייד → הגדרות → "ייצוא קבצי HTML תסקירים למחשב" (עשוי לקחת זמן)
5. העתק את קבצי ה-HTML מ-Download למחשב
6. לאחר טעינת הטבלה, לחץ "טען קבצי HTML" ובחר את כל קבצי ה-HTML

מספר תסקיר תאריך לקוח סוג מכונה מס׳ רישוי גרסאות
