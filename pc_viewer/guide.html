מה זו תבנית?

תבנית מגדירה אילו שדות יופיעו לכל אביזר, באיזה סדר, וסוג הקלט. תבנית שונה לכל סוג ציוד (שרשרת, כבל, אביזר רגל, ווים).

יצירה / עריכת תבנית

  1. לחץ "טופס חכם (עריכת תבנית)"
  2. בחר תבנית קיימת או "חדשה"
  3. הוסף / ערוך / מחק שדות
  4. לכל שדה: שם · סוג · חובה / מפתח
  5. שמור את התבנית

מה זה viewer.html?

קובץ HTML עצמאי שפועל ישירות בדפדפן PC (Chrome/Edge) — ללא שרת, ללא התקנה. פותחים בלחיצה כפולה.

יכולות המנהל

  • גרירת קבצי JSON + HTML ישירות לחלון
  • לשוניות: מכונות הרמה · קולטי אוויר
  • חיפוש: מספר, לקוח, סוג, תאריך
  • מיון לפי כל עמודה
  • סיכום: כמות תסקירים + עם HTML
  • צפייה בתסקיר מלא בחלון מוד
  • הדפסה עם שוליים תקינים
  • מצב כהה/בהיר (לפי OS)
